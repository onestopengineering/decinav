# /decinav-review

Review every `proposed` ADR with the human and run the review command they choose.

## Prerequisites

- `decinav` on `PATH`; run from the project root (contains `docs/adr`).

## Steps

1. **List proposals.** Run `decinav context --compact` and collect the lines whose status is `proposed`. If none, say so and stop.
2. **Load the proposed bodies only.** Run `decinav context --format json --ids <proposed IDs, comma-separated>`.
3. **Present each one**, in ID order: ID and title; the Decision section verbatim (it is usually a few sentences); relationships with their reasons; `provenance.generated_by`, `provenance.generator`, `provenance.sources`; `freshness.state` with `commits_since` when not fresh. Then ask: **accept**, **reject**, or **skip**? One ADR per question.
4. **Apply only an explicit answer.**
   - accept: run `decinav accept <ID>`. Several accepted in a row may be batched as `decinav accept ADR-0007 ADR-0008` after the user has answered for each.
   - reject: run `decinav reject <ID>`. If it refuses because another ADR references it, show the message and ask the user what to do; do not edit files to force it.
   - skip: leave it proposed.
   - No answer, or an ambiguous one: treat as skip and say so.
5. **Attest optionally.** If the user says an accepted ADR was checked against the current code, run `decinav attest <ID>` so its freshness resets.
6. **Finish.** Run `decinav validate` and show the result. Mention that the graph in `docs/adr/README.md` was regenerated by the accept or reject commands.

## Token notes

- This is the only skill allowed to load several bodies, and only the proposed ones via `--ids`. Never load accepted ADRs here.
- Quote the Decision section (needed for judgment) but not Context or Consequences unless the user asks.

## Output

A table of ID, title, and outcome (accepted / rejected / skipped), followed by the validate line.

## Never

- Never run `accept` or `reject` without an explicit answer for that ADR.
- Never edit `docs/adr/*.md` to change a status by hand.
- Never summarize a Decision section so loosely that the human cannot judge it; quote it.
